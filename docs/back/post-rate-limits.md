# 投稿回数の制限

ユーザーごとの直近1時間の上限は、お題作成10件、作品送信試行20件です。掲載中5スロット・1人1お題1作品の制限とは別に適用します。変更する場合は `back/app/post_limits.py` の定数を変更します。

Firestoreのusers文書に日時を上限件数まで保存し、既存の投稿トランザクションで読み書きします。複数インスタンスでも同一ユーザーの並行更新が競合検出されます。別ユーザー・別投稿種別は独立します。古い日時は次回投稿で除去します。

上限到達時は429 RATE_LIMITEDと既存のRetry-Afterを返します。Retry-Afterは再試行間隔であり、成功までの待ち時間ではありません。直近1時間の枠が空くまで制限は継続します。

お題は作成成功時だけ消費します。作品は予約成功時に消費し、画像不正・審査拒否・外部障害も試行として数えます。確定済みの同一内容の再送、処理中の重複、資格不備は消費しません。上限到達後でも確定済みの同一投稿の結果は取得できます。

未認証リクエスト・一般API・Visionデモ・本文の転送・複数アカウントをまとめて制限するものではありません。インフラ側での制限・監視は別途検討してください。
