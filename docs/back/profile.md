# プロフィールの編集・受信者への公開

プロフィール編集と受信作品からの作者閲覧の現行仕様をまとめています。画面全体は [デザインガイド](../flont/design.md)、保存項目は [DB・API仕様](../database/DB_v0.md) を参照してください。

## 本人の編集

- マイページの「プロフィールを編集」でユーザーネーム・自己紹介・SNSリンクを更新します。
- `GET /api/v1/me` で取得し、`PATCH /api/v1/me/profile` で本人の情報を更新します。
- ユーザーネームは1〜24文字。未指定なら既存値を保持します。空白だけ・制御文字は拒否します。
- 自己紹介 `bio` は最大300文字、SNS `socialLinks` は最大5件。更新時には両項目を送ります。
- リンクは `type`・`label`（1〜40文字）・`url`（1〜2048文字）。種別は `x`・`instagram`・`pixiv`・`youtube`・`other`。
- HTTPSだけを受け付け、資格情報付きURLと重複URLを拒否します。既知SNSの種別ではホストも検証します。
- 新旧ユーザーとも未保存の `bio`・`socialLinks` は空文字・空リストとして取得できます。一括DB移行は行わず、編集保存時に書き込みます。
- 登録の再送で名前・累計・枠・ピンを初期化しません。登録応答と保存済みプロフィールの取得は区別し、最新プロフィールは `GET /api/v1/me` で取得します。

## 作品ごとの公開選択

`POST /api/v1/artworks` のmultipart項目 `shareArtistProfile` は既定falseです。公開を選んだ作品に `artistProfileVisibleToRecipient` を保存します。チェックを外した送信では、作者情報を受信者に公開しません。

受信箱・作品詳細では `artistProfileAvailable` を使って作者名・導線を切り替えます。公開時は `GET /api/v1/me/artworks/{submission_id}/artist-profile` で現在の作者情報を取得します。返すのは `uid`・`nickname`・`bio`・`socialLinks` です。メールや非公開カウンターは返しません。

次の条件をすべて満たす場合だけ取得できます。

- 認証・登録済みactiveの受信者本人である。
- 作品が存在し、未削除かつ閲覧期限内である。
- 送信時に作者がプロフィール公開を選んでいる。
- 作者ユーザーが存在し、activeである。

不許可・欠損・期限切れは共通404です。一般公開のプロフィールURLや、相手のお題カード一覧は提供しません。作者プロフィールを編集すると、公開済み作品からも最新内容が表示されます。

## 画面確認

[起動方法](../startup.md) のプレビューでは編集結果は起動中の画面内だけに反映します。永続保存・権限・非公開・期限切れの確認は通常ログインで行います。

外部リンクでは遷移先を確認できる表示にし、ブラウザーで開けない場合の失敗表示も確認します。スマホ・タブレット・PC幅で編集・閲覧を確認してください。

## 今後の検討

アイコン・代表作品、プロフィール全体の一般公開、公開累計、報告・ブロックは今回の対象外です。導入時には画像の権利・審査・容量・保持期限・削除、一般公開範囲、リンク悪用時の運用を別途決めます。受信者限定画像を代表作品として流用しません。
