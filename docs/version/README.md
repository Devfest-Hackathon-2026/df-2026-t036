# バージョン履歴

バージョンごとに `v1.0.md`、`v1.1.md` のようなファイルで管理します。

| バージョン | 状態 | 公開日 |
|---|---|---|
| [v1.0](v1.0.md) | 未リリース | 未確定 |

## 更新ルール

1. 開発中のバージョン文書に、追加機能・不具合修正・設定変更とPR番号またはコミットを追記します。
2. 公開時に状態・公開日・実際のGitタグを記録します。ファイル作成やdevelopへのマージだけでは公開済みにしません。
3. 次の開発では新しいバージョン文書を作り、この一覧へ追加します。過去版は誤記訂正を除き更新しません。
4. DB移行・設定追加・利用者が必要とする作業は各版に明記します。

これはアプリの更新履歴です。文書のファイル名を変えても `pubspec.yaml` のアプリバージョンやGitタグは自動変更されません。
