# 変更履歴

利用者・開発者に影響する変更をPRとコミットに紐づけて記録します。公開リリース番号は未確定のため、現段階では付けません。

## 未リリース

### ドキュメント整備（2026-11-10）

- 環境構築を現在のFlutter・Python・CI構成に合わせて整理。
- 通常起動、認証なしプレビュー、DockerへのADC受け渡し、停止・トラブル対処を [起動方法](startup.md) に集約。
- 利用規約の画面・本文には「草案」表記がないことを確認。別文書のプライバシーポリシーは既存の草案状態を維持。

プロフィールの `bio`・`socialLinks` がない既存ユーザーには空値を返し、編集保存時にDBへ保存します。マージだけで既存ユーザー全員を一括更新する処理はありません。

## 更新方法

1. 機能・不具合修正・起動設定の変更時に「未リリース」を更新します。
2. レビュー可能なPR番号またはコミットを記載し、動作変更と移行・設定作業の有無を記録します。
3. 公開時に確定したタグ・日付へ移し、次の「未リリース」を作ります。developへの統合と本番公開は区別します。
4. 記録のない古い変更はGit履歴を参照します。このファイルは全コミットの自動生成一覧ではありません。
