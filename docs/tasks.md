# 開発タスク一覧（M0・M1）

[総合仕様書](specification.md) と [DB・API仕様書](database/DB_v0.md) の確定事項をもとにした開発タスクです。DB・API仕様書の追加実装案はレビュー後に採否を確定します。更新日：2026年11月5日。
チェック済みは現在のひな形で実装・確認した項目のみです。クラウドへのデプロイ完了を意味しません。仕様変更時は仕様書と本一覧を併せて更新します。

## 進め方・仮担当

| 仮担当 | 主な範囲 |
|---|---|
| A | Flutter、画面・共通UI、入力・表示、端末検証 |
| B | Firebase、Google認証、Firestore、アイデア・ピン |
| C | FastAPI、Cloud Run、画像・作品、既読・自動更新・期限削除 |
| 全員 | 契約・権限設計の合意、レビュー、統合テスト |

実際の担当者と期限は未割り当てです。各タスクのIDをIssue・PRに記載し、完了条件を確認したうえでチェックします。分担は仕様書の仮案であり、実行時の担当を固定するものではありません。

実装順は **M0 → 登録・アイデア → 作品送受信 → 既読・自動更新・期限削除 → 限定テスト** です。M0の契約・権限設計後は、Aの画面実装とB・Cの機能実装を並行して進められます。

M1-01とアイデア・投稿資格判定の実装を前提とします。

- [ ] M1-19【C・A】：受信作品の手動削除を実装。即時に閲覧不可とし、画像・作品を再試行可能に削除する。いいね・累計は維持する。描いた数と履歴は維持する。
